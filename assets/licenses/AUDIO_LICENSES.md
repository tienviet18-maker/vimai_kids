# Audio licenses — ViMai Kids

Audio clips bundled in this app were generated **offline** by the ViMai Kids build pipeline.
The Piper / Piper Plus models are **not** shipped in the APK or web build.

Checked: 2026-08-28

## Vietnamese

- Language: Vietnamese (`vi`)
- Engine (development only): Piper
- Voice / model: `vi_VN-vais1000-medium`
- Dataset / license: CC BY 4.0
- Model card: https://huggingface.co/rhasspy/piper-voices/tree/main/vi/vi_VN/vais1000/medium
- Attribution: Voice **vais1000** (Piper). Audio generated by ViMai Kids build pipeline.

## Japanese

- Preferred engine (development): Piper Plus Tsukuyomi-chan
- Model: https://huggingface.co/ayousanz/piper-plus-tsukuyomi-chan
- Corpus: つくよみちゃんコーパス / 夢前黎 — https://tyc.rei-yumesaki.net/material/corpus/
- Fallback engine when Piper Plus cannot run (for example Python 3.14 + onnxruntime): Piper `ja_JA-hi_fi_captain-medium`
- Fallback model: https://huggingface.co/rhasspy/piper-voices/tree/main/ja/ja_JA/hi_fi_captain/medium
- Build-time bake fallback: Windows Speech API Japanese voice (`ja-JP`) when Piper Japanese models cannot synthesize on this machine. Only the resulting WAV is shipped. The OS voice is not used at runtime.
- Japanese clips are always Japanese. They are never synthesized with Vietnamese or English voices.
- Attribution when Tsukuyomi is used: **Tsukuyomi-chan (夢前黎)**
- Attribution when the official Piper Japanese fallback is used: Piper Japanese voice **hi_fi_captain**
- Attribution when Windows SAPI bake is used: Japanese WAV baked at build time from the installed `ja-JP` voice
- Audio generated by ViMai Kids build pipeline.

## Runtime

- Only the generated WAV files under `assets/audio/` are packaged.
- The app does not download audio at runtime.
- The app does not use OS / Chrome system TTS for Vietnamese or Japanese learning audio.
- Missing production assets fail `tool/check_audio_assets.py` and unit tests.

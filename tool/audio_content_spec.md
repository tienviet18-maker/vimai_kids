# Vietnamese & Japanese audio content specification

Do **not** regenerate the 913-file inventory because quality is imperfect.
Replace only files marked in `tool/audio_inventory.json` (or a future `NEEDS_REPLACEMENT` list).
Keep IDs, paths, and `AudioService` unchanged.

## Runtime rules (already implemented — preserve)

- Bundled WAV first
- Same-language TTS fallback only
- Explicit language on every request
- One `AudioPlayer`, queue, debounce, lifecycle stop
- Japanese never through Vietnamese/English; Vietnamese never through Japanese/English

## Vietnamese categories

| Category | Example spoken text | Intent | Typical duration | Source now | Human recording |
|---|---|---|---|---|---|
| Letter name | a, ă, â, bê, xê, dê | School letter name | 400–900 ms | Piper vais1000 | Required for “teacher quality” |
| Letter sound | a, bờ, cờ, dờ, đờ | Phonics onset | 350–800 ms | Piper | Required |
| Phonics syllable | ba, be, bi | Blend | 400–900 ms | Piper | Optional |
| Rime | an, ang | Vần | 400–900 ms | Piper | Optional |
| Word | ba, mẹ | Word | 400–1100 ms | Piper | Optional |
| Sentence | Mẹ yêu bé. | Short sentence | 800–2000 ms | Piper | Optional |
| Praise | Giỏi lắm | Encouragement | 600–1000 ms | Piper (`vi_phrase_gioi_lam`) | Optional |
| Instruction | (few clips) | UI prompt | varies | Piper | Optional |

Letter names must **not** be generated by naively spelling Latin letters in English TTS.

## Japanese categories

| Category | Example | Intent | Source now | Honest quality |
|---|---|---|---|---|
| Kana character | あ | Pronunciation | Bundled `ja_*` WAV (often SAPI ja-JP bake) | Educational, not native studio |
| Example word | あさ | Vocabulary | `ja_*_example` | Same |
| Praise after correct | Giỏi lắm (VI) | Feedback | `vi_phrase_gioi_lam` | Keep; do not mix JA TTS into VI praise |

Future native JA recordings should drop in at the same `assets/audio/ja/...` paths.

## Replacement procedure

1. Mark IDs in inventory (`NEEDS_REPLACEMENT` / quality flags).
2. Generate or record **only those IDs**.
3. Run `python tool/check_audio_assets.py` — expect `missing=0`.
4. Do not run `--force-vi` or full Piper rebuild.
